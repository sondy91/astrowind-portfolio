# Portfolio Project - Personal Development Mode

## Override Global AGENTS.md Settings

This is a personal portfolio project on GitLab. Use simplified workflow:

### Workflow

- **Branching:** Direct commits to main branch
- **Commit format:** Conventional commits without ticket IDs
  - Format: `<type>: <description>`
  - Examples: `feat: migrate to Vite+`, `chore: upgrade to Astro 6`
  - Types: feat, fix, chore, docs, style, refactor
- **GitLab Issues:** Can create issues for tracking (optional, not required)
- **No JIRA integration**
- **No stacked PR workflow**

### Testing

- **Strategy:** Build verification only
- **Commands:** `vp check` (lint/fmt/types) then `pnpm build` (Astro build)
- **Dev server:** `pnpm dev` — use `pnpm dev -- --host` for WSL→Windows browser access
- **No test suites required** (manual testing acceptable)

### Tooling

- **Toolchain:** Vite+ (unified Vite/Vitest/Oxlint/Oxfmt/Rolldown)
- **Package manager:** `vp add` wraps pnpm — use `vp add <pkg>` / `vp add -D <pkg>` instead of `pnpm add`
- **Node version:** 24.14.1 (via mise)
- **Pre-commit hooks:** Enabled via `vp prepare`

### Deployment

- **Platform:** Vercel
- **CMS:** Sanity Studio at `/admin`
- **Build command:** `vp build`
- **Preview command:** `vp preview`

### Git Protocol

1. Make changes directly on main
2. Test locally: `vp check && vp build`
3. Commit with conventional format
4. Pre-commit hooks run automatically
5. Push to GitHub (primary)
6. Vercel auto-deploys

### Framework Considerations

- **Current:** React 19 (minimal usage, mostly Astro components)
- **Potential migration:** Consider Vue.js if more interactive components needed
- **Recommendation:** Keep React for now, evaluate migration separately

## Repository Info

- **Primary remote:** GitHub
- **Mirror:** GitLab (gitlab.com/asonderman/astrowind-portfolio) — synced via GitHub Action
- **Not a work project** - no enterprise workflows apply
- **Keep it simple** - this is a personal portfolio site
